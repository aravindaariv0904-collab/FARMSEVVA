# Project Roadmap

This document maps out the roadmap milestones for the Farm Seeva ecosystem.

## Phase 1: Prototype (Completed)
- [x] Initial design UI in static html format (`farm-seeva-` repository).
- [x] Multi-language support baseline translations.
- [x] Local mock responses for agricultural queries.

## Phase 2: Microservices Monorepo (Completed)
- [x] Migrate static frontend to Vite + React structure.
- [x] Secure JWT-based registration and login flows.
- [x] Integrate Prisma ORM with relational SQL databases.
- [x] Implement Terra AI assistant service supporting both Gemini and Anthropic Claude.
- [x] Establish backend tests coverage.

## Phase 3: Hardware Integration (Q3 2026)
- [ ] Add direct IoT soil moisture sensor hook integrations.
- [ ] Implement Bluetooth Low Energy (BLE) sync utilities to pull telemetry straight from local portable NPK sensor kits.
- [ ] Establish automated push alerts for weather and pest spreads based on geolocations.

## Phase 4: Marketplace & P2P (Q4 2026)
- [ ] Build a direct Peer-to-Peer (P2P) equipment rental marketplace for tractors and machinery.
- [ ] Connect local farmers directly to wholesalers using transparent pricing graphs.
